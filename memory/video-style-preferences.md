- Keep the user's original voice in every edit.
- Wanted format: **2D animation in explainer style**. The user's own character (hoodie guy from their character sheet) appears inside the topic's world and narrates with **lip-sync**; the rest is scenes, icons, cards, maps and motion graphics matching each script line. The approved shorts template was "Prachin Juger Manush - 2D Explainer (9x16).mp4" (2026-11-06).
- **Science/body topics:** whenever the voiceover explains anything scientific or about the body/anatomy, visualize it very clearly (diagrams, cutaways, step-by-step animation) so viewers instantly understand.
- Long videos: strong hook in the first seconds, and design for retention (frequent visual changes, pattern interrupts, open loops).
- 2026-11-06 request for the NEXT video (after approving Prachin Jug long video): **no plain blue/navy studio backgrounds** and **no house/room-type backgrounds** (the modernRoom/studio bokeh looks); still use the user's character; more real animation (not just icons/motion graphics), fresh new scene types, **much more pro map animation**, strong **colour grading**, more polished character animation, retention must never drop.
- Too much on-screen text and a single background colour were rejected → minimal keyword text only, distinct colour per section.
- Wants "pro" visuals: real/convincing maps, constant motion, particles, HUD-style details.
- Gives element mix by percentage sometimes (e.g. cartoon 25%, infographic 20%, map 15%) — follow it.
- Vector characters drawn by Claude were rejected; use cut-out rig from the user's character sheet (front arm redrawn as one continuous sleeve stroke — cut-apart arm pieces looked "broken").
- Order clips by what is said in the voiceover, not by file number.
- Likes a small phone-preview render alongside the full-res file.

**Why:** Feedback across the Iran Cable Explainer, TOP 5, and Prachin Jug videos (2026-11).
